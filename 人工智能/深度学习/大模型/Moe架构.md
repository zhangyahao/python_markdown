## 一、MoE 整体流程

### 训练阶段

```text
输入 token
  → 前置网络（Attention、FFN、LayerNorm 等）
  → 前向计算出隐藏状态 h        ← h 是激活值，不是参数
  → h 同时送给：
       路由器：h · W_g → 分数 s → softmax → 概率 p → 取 Top-K
       候选专家：每个专家是一个 FFN
  → 只有被选中的 Top-K 个专家对 h 做 FFN 前向，得到 E_i(h)
  → MoE 层输出：y = Σ p_i · E_i(h)
       ↑ 路由输出 p 与专家输出 E 在此相乘汇合
  → 继续后续层 → 最终损失 L
  → 反向传播：
       从 L 到 y：得到 ∂L/∂y
       在 y 处分叉：
         路 1（路由器）：
           ∂L/∂p_i = ∂L/∂y · E_i(h)   ← 用专家输出 E_i(h) 当常数
           → ∂L/∂W_g
           → 更新 W_g
         路 2（专家）：
           ∂L/∂E_i = ∂L/∂y · p_i      ← 用路由输出 p_i 当常数
           → 更新被选中专家的参数
       两路梯度都继续往前传，更新前置网络参数
  → 未选中专家在当前 token 上不参与、不更新
  → 参数更新后，下次前向：新的 p 和新的 E 再次在 y 处相乘汇合
```

### 推理阶段

只做前向，不更新任何参数。

## 二、核心组件与参数

| 组件   | 是什么                       | 参数       | 作用                  |
|------|---------------------------|----------|---------------------|
| 前置网络 | Attention、FFN、LayerNorm 等 | 大量参数     | 前向算出 h              |
| 路由器  | 线性层 + softmax             | \(W_g\)  | 根据 h 选 Top-K 专家，给权重 |
| 专家   | 多个并行 FFN                  | 每个专家独立参数 | 被选中后对 h 做变换         |
| h    | 激活值向量                     | 不是参数     | 前面层输出，同时给路由和专家      |

关键区分：

- **h 是激活值**，不是参数，不被直接更新。
- **路由器不是 FFN**，是单层线性 + softmax，属于门控/分类器。
- **专家才是 FFN**，通常两层 MLP + 非线性激活。
- **只有被选中的专家走 FFN**，未选中专家完全不参与当前 token。

## 三、逐条总结

### 1. 大模型为什么会有专家？

因为想在有限算力下扩大模型容量。  
MoE 把 FFN 拆成多个专家，每个 token 只激活 Top-K 个，实现**参数与计算解耦**。  
专家是训练中自动分化出来的，不是人工指定。

### 2. 负载均衡会不会导致专家变成全能型？

传统辅助损失过强时，会迫使路由器近似均匀分配，导致专家看到相似数据，可能同质化。  
方案 6 用**不参与梯度的动态偏置**做软均衡，只把边际 token 推给冷门专家，不干扰路由器学习，所以不会导致全能化。

### 3. Token 怎么选择不同子网络？

不是有一个前置模型分析语义再派给专家。  
路由器就是一个线性层，再 softmax，再取 Top-K。  
它不知道语义，只是在隐藏空间里做线性投影。  
“什么 token 去哪个专家”是训练中路由器和专家协同进化出来的。

### 4. 路由器是不是 softmax 分类器？

是，但准确说是：**稀疏的、端到端训练的 softmax 门控**。  
它没有人工标签，输出用于加权专家输出，而不是硬分类。

---

## 四、一句话心智模型

**前置网络前向算出 h；路由器用 h 选专家并给权重；被选中的专家用 h 做 FFN**
**前向；输出加权求和后继续往后传；损失反向传播，更新前置网络、路由器和被选中专家的参数；未选中专家本轮不更新；下次前向，新的参数让路由和专家配合得更好。推理时只前向，不更新。**
